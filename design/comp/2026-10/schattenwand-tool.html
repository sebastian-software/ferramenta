Oniguruma ended. The engine goes on.

Oniguruma’s C project closed on April 24, 2025, after more than twenty years as the regex engine that TextMate grammars are written for. Ferroni carries it forward.

  • Same engine, verified

    A line-by-line port that keeps Oniguruma’s module structure and optimization pipeline. Verified against the upstream UTF-8 tests, with differential checks against C.

  • Memory-safe, no C toolchain

    cargo add ferroni and build: no bindgen, no C compiler, no node-gyp.

  • Measured on real code

    From single regex searches to complete TextMate grammars, the benchmark reports record input, timings, and reproduction steps.

  • The scanner, built in

    vscode-textmate and Shiki tokenize through vscode-oniguruma’s scanner. Ferroni ships a scanner of the same shape, UTF-16 offsets included.
