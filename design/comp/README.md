# Design comps

The comp of the current direction, "Monografie" (ADR-0012), is in
[2026-11/monografie/](2026-11/monografie/). It is a working page, not a
contract: the package's `monografie.css` and the kit at `/kit/` are.

`Monografie`, `Typenschild`, `Cor-Ten`, `Schattenwand`, `Schmiede`,
`Blankstahl`, `Werkbank` and `Maschinenpark` are German names in the design
vocabulary and the ADRs; site copy, code and documentation are US English. The
historical German design critiques in `.impeccable/critique/` are working
material of the design tooling.

Earlier comps are in Git history: the "Typenschild" comps (ADR-0008) and the
Ferra page designs (ADR-0010) until they were removed with the old themes in
November 2026, and the directions before them before the tag
`design-residue-2026-09-30`.
