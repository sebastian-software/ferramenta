The web's infrastructure, reforged in Rust.

Ferramenta — Italian for hardware store — is a family of Rust-native tools that keep the APIs you already know. Held to the originals by differential testing, and built to outrun them.

Held to the originals

Proven, not promised

Compatibility is enforced, not advertised. Differential suites run every tool against the original — the Hunspell oracle, the mirrored Shiki tests, svgo byte for byte, Oniguruma's own C library.

Open standards first

CommonMark and GFM, PO and ICU MessageFormat, Hunspell dictionaries, TextMate grammars. We build on what the ecosystem already agreed on — never on formats only we control.

The APIs you already know

Drop-in by design: the same options, the same output. Adopting a Ferramenta tool is a swap, not a migration.

Native speed, safe defaults

Rust cores without a C toolchain. Sanitized output, bounded memory and time — production behavior out of the box, not after configuration.
