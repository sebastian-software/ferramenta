<FerraSection id="install" label="01 / Install" intro="Add the Markdown renderer to your Rust project." title="Install Ferromark.">

```sh
cargo add ferromark
```

Ferromark renders Markdown as HTML. Start with one document, then choose options
and output hooks as your application grows.

</FerraSection>

<FerraSection id="first-document" label="02 / Render" intro="A string in. HTML out." title="Render your first document." surface="pewter">

```rust title="src/main.rs"
fn main() -> Result<(), ferromark::ParseError> {
    let html = ferromark::to_html("Hello, **world**!")?;
    println!("{html}");
    Ok(())
}
```

The rendered HTML is `<p>Hello, <strong>world</strong>!</p>`.

<FerraSection id="trust" label="04 / Trust" intro="Choose an explicit policy before rendering untrusted input." title="Choose your trust policy." surface="plain">

Rust preserves raw HTML by default. For untrusted Markdown, enable
`HtmlRendererOptions::sanitize`:

```rust
use ferromark::{to_html_with_options, HtmlRendererOptions, ParserOptions};

let render_options = HtmlRendererOptions {
    sanitize: true,
    ..Default::default()
};
let html = to_html_with_options("Hello, **world**!", ParserOptions::default(), render_options).unwrap();
```

The Node.js API has different defaults. Read the
[rendering policy](https://ferromark.dev/guide/rendering/) before accepting
untrusted input.
