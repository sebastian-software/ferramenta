Ferrometro is a units-of-measure engine. It parses quantities, checks that
their dimensions agree, and converts between units. Units are written the way
[UCUM](https://ucum.org) writes them, so a value means the same thing in every
system that reads it.

<RuntimeTabs />

## Install

You need Rust 1.80 or newer. In an existing Cargo project, run:

```bash
cargo add ferrometro
```

Or add it by hand:

```toml
[dependencies]
ferrometro = "0"
```

## Your first quantity

A quantity is a number and its unit, kept together. `ferrometro::parse` reads
one, and `Quantity::to` converts it:

```rust title="src/main.rs" {3}
fn main() -> Result<(), ferrometro::Error> {
    let speed = ferrometro::parse("12 km/h")?;
    let metric = speed.to("m/s")?;
    println!("{metric}");
    Ok(())
}
```

A long line stays on its line and the sheet scrolls sideways:

```rust
let report = ferrometro::convert_all(["3 ft 4 in", "12 km/h", "a deliberately long fictional quantity"], "m")?;
```

Try a conversion. The input and the option are this page's own state; the
example only shows them.

## Units and dimensions

Every unit has a dimension: how much length, mass and time it is made of. Two
quantities convert only when their dimensions agree.

| Unit | Dimension             | Written as | Note                                         |
| ---- | --------------------- | ---------- | -------------------------------------------- |
| m    | length                | `m`        | The base unit of length                      |
| km/h | length / time         | `km/h`     | A compound unit, read left to right          |
| N    | mass · length / time² | `kg.m/s2`  | Defined by its base units, never by a factor |

## Configuration

Options apply to one call; a configuration file sets them for the whole
project.

| Option      | Default | Effect                                                |
| ----------- | ------- | ----------------------------------------------------- |
| `precision` | `6`     | Significant digits in a formatted result              |
| `system`    | `"si"`  | The unit system a bare quantity is converted into     |
| `strict`    | `false` | Rejects units that are spelled outside UCUM's grammar |
