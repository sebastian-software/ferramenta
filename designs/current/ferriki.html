Grammars and themes

Familiar inputs, a native engine.

Keep the editor contract

TextMate grammars started in TextMate and power highlighting in VS Code and Shiki. Ferriki runs a Rust port of VS Code's TextMate tokenizer and uses Ferroni for the original pattern language. Shiki-compatible HTML calls keep familiar shapes. Compatibility is checked against pinned upstream tests, with supported, deferred and out-of-scope cases recorded explicitly.

Output

Tokens, HTML and CSS with distinct jobs.

Render once. Choose how it is styled

Use inline styles for a self-contained code block, or class-based output with nested scopes for stylesheet themes. codeToHtmlWithCss returns HTML and CSS. A theme map can switch presentation without highlighting the source again. Rust callers can work with tokens and rendering APIs. Node.js callers use the native addon. Keep a loaded highlighter for repeated work instead of rebuilding it for every block.

Delivery

Send the result to the browser.

Move highlighting into the build

With the Vite integration, code() and the Code component become highlighted HTML and CSS during the build. The browser receives the result; grammar and engine loading stay in the build step. Languages and themes load on demand from a release-pinned asset service, are verified by SHA-256 and are cached. A mirror or warm cache supports offline builds.
