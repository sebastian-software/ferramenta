Prune from the include pattern

A scoped include pattern identifies the roots that can match. Ferralk uses that information while walking, rather than treating selection only as a filter on an already visited tree. Filenames remain raw bytes and native Path values from directory reads to matches. Consumers do not lose filenames to a forced UTF-8 conversion.

Glob semantics

Choose the pattern contract

A single star stays inside one path component in the shell-style contract. PatternOptions::walker() enables recursive stars, braces and extglobs for standalone matching, just as the walker does. Default standalone pattern options intentionally keep those syntax extensions off. Choose options when moving an existing matcher rather than assuming every library reads the same pattern alike.

Evidence

Measure the work you actually do

The matcher and walker are checked against a frozen zlob reference. Ignore verdicts are replayed against Git itself. Recorded benchmarks describe concrete tree shapes, cache conditions, hosts and worker budgets; they are not a promise of one universal ranking. The matcher crate forbids unsafe. The broader workspace records its named, limited exceptions explicitly.
