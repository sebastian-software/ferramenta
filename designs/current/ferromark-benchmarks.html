What the timing includes

Fresh includes setup, processing, owned output and destruction. Reuse retains public state where the API permits. No file I/O, process startup or output normalization is timed.

Read the conditions before the ranking

The extension lane enables tables, strikethrough and task lists. This is not full GFM. These explicit settings differ from library defaults. One shared workstation does not establish a universal ranking or statistical significance.
