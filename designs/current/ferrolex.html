Wordforms, not just a bag of strings

Hunspell dictionaries describe more than a list of base words. Ferrolex loads existing dictionary and affix data without linking the native Hunspell library. Reviewed compatibility is recorded for exact pinned dictionaries and probes. This is not a blanket claim of complete Hunspell compatibility. Check the locale matrix for the dictionary you intend to ship.

Suggestions

Deterministic decisions.

Suggestions that can be reviewed

The same dictionary and input produce the same suggestion ordering. Keep suggestion behavior visible in tests and review it against real text rather than assuming a language model will repair the result. Optional normalization is an explicit library policy. It is separate from future case-folding behavior.

Boundaries

Extract the right text first.

Let the integration own the format

A Markdown tool extracts prose. A code-aware integration decides which identifiers or comments belong in the check. Ferrolex owns dictionary loading, word checks and suggestions; the caller owns document parsing and language context. The Rust engine is the product core. The direct Node.js binding is release-gated but not yet published to npm in this source snapshot. C ABI, Python, LSP and editor integrations remain evaluation prototypes.
